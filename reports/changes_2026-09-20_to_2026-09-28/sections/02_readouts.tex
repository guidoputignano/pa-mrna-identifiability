\smallskip
\noindent The audit's own verdicts are these. Only c2+c8 is worth buying, and it improves on
c2 alone by $\rn{audit.p10_c2c8_lo}$ to $\rn{audit.p10_c2c8_hi}\%$. c9 adds nothing in any
combination. Table C overstates c2, because the supported width is about
$\rn{audit.p10_width_w}$, not $\rn{fus.p2_frac}$. The between-patient spread of the scatter
decides the remaining routes; it could be measured in \rn{audit.p10_repeat_pts} patients at
\rn{audit.p10_repeat_draws} draws each.
\textbf{The paper has no fusion step.} Its three tiers form a dependency chain. Tier 1
decides which structure Tiers 2 and 3 calibrate, and nothing Tier 3 buys holds unless
Tier 2's increment measurement does. No external anchor, alone or combined with others,
opens the disease range: §7.1 lists \rn{lnew.six_routes} routes, each tested and closed.

\W The readout passages are \textbf{unchanged}: Remark 2, the §S1.14 table and §S1.16.2
read the same in both drafts. The C3 correction predates this window (see §6.3).
\emph{Tier 1, §6.2:} the 27 Sept draft opens with ``What to run first, and it is one blood
draw'' (on main \rn{git.main_tier1first}). It also states that Tier 1 is a \emph{structure}
test, not a goodness-of-fit threshold. \emph{Tier 2, §6.3:} the Table 10 floors and the
$\rn{new.tier1_visits_at_pub}$-draw count are now generated (\texttt{\rn{gen.tier1}}); their
values are unchanged. Table 11 is unchanged. \emph{§7.1:} the diet values moved (§6.2).
Route 6 still carries the below-nominal clause that Table B could not reproduce.

\Out{Three readouts are used or requested, and they are gated in sequence. The combination
analysis exists only in the audit, and no combination brings the monthly record inside the
gate at $\rn{calc.dis_pct}\%$ capacity.}
